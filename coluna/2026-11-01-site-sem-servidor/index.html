Um site sem servidor

Por que este site é só um punhado de arquivos de texto.

Este site é montado a partir de arquivos markdown por um script de biblioteca padrão. Não há banco de dados, formulário nem script: só HTML e uma folha de estilo.

A fonte é local; o site é derivado e regenerável.
